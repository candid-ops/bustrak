# BusTrak - Modern Bus Management System

## Features
- Multi-role authentication (Admin/Driver/Customer)
- Live GPS bus tracking
- Online seat booking
- M-Pesa payment integration
- Email notifications

## Tech Stack
- Laravel 10
- Bootstrap 5
- MySQL
- M-Pesa API

## Installation
1. Clone repository
2. Run composer install
3. Copy .env.example to .env
4. Run php artisan key:generate
5. Configure database
6. Run php artisan migrate
7. Run php artisan serve
